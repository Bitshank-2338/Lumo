# Lumo Roadmap

This roadmap communicates direction, not guaranteed delivery dates. Priorities may change as the project is tested with learners and contributors.

## Now: stabilize the hackathon foundation

- Improve knowledge-base upload reliability and error messages.
- Strengthen the public demo’s authenticated workflow and recovery states.
- Document the distinction between the public demo and full local application.
- Expand regression tests for core learning journeys.
- Improve setup, provider configuration, accessibility, and contributor onboarding.
- Audit branding, attribution, privacy boundaries, and deployment documentation.

## Next: connect the complete learning journey

- Move from one demo workflow to richer saved learning projects.
- Connect source-grounded lessons, concept maps, questions, revision plans, and books.
- Improve progress and mastery tracking.
- Add export and sharing controls with privacy-safe defaults.
- Make agent and model integrations easier to configure and diagnose.
- Establish stable skill metadata, validation, and versioning.

## Later: build Lumo Hub safely

- Define a reviewed community skill submission process.
- Add permission declarations and security review for skills.
- Support version history, compatibility metadata, ratings, and reporting.
- Add controlled installation, updates, and removal.
- Create educator and learner collections without exposing private material.

## Contribution opportunities

High-value contribution areas include:

- accessibility and keyboard navigation;
- documentation and tested setup guides;
- knowledge upload diagnostics;
- tests for authentication, retrieval, and saved workflows;
- learning-science-informed tutoring and revision flows;
- privacy, threat modeling, and secure skill execution; and
- performance on ordinary learner hardware.

Please open a feature or skill proposal issue before starting a large roadmap item.
