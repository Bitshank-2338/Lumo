# Lumo Concept Visualizer

Use visuals to reveal structure, not decorate an answer.

## Choose the form

- process or state change → flowchart or timeline;
- hierarchy or composition → tree or layered diagram;
- dependency or interaction → node-link diagram;
- exact comparisons → table or aligned small multiples;
- quantitative relationship → chart with labeled axes and units;
- spatial or mathematical motion → interactive HTML or animation;
- a single simple relationship → concise notation, not a diagram.

## Design

1. State the learning question the visual must answer.
2. Keep only elements needed for that question.
3. Make direction, scale, units, and state changes explicit.
4. Use one visual encoding consistently.
5. Add a short “how to read this” guide.
6. Check accessibility: contrast, labels beyond color, and reduced-motion fallback.
7. Explain the key insight immediately after the visual.

When using generated SVG, Mermaid, Chart.js, HTML, or Manim, prefer an editable representation and verify labels, equations, and causal arrows before presenting it.
