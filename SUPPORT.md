# Support

Lumo is an early-stage open-source project maintained on a best-effort basis.

## Before asking for help

1. Read the main [README](README.md) and [contribution guide](CONTRIBUTING.md).
2. Search existing [issues](https://github.com/Bitshank-2338/Lumo/issues) for the same error or question.
3. Confirm you are using Python 3.11–3.13 and Node.js 22+.
4. Retry with the latest `main` branch when practical.
5. Remove API keys, tokens, personal documents, and private data from screenshots and logs.

## Where to ask

- Reproducible product failure: use the **Bug report** template.
- Proposed product improvement: use the **Feature request** template.
- First-party or future community skill: use the **Lumo skill proposal** template.
- Documentation problem: use the **Documentation issue** template.
- Setup or usage help: use the **Question** template.

Please include the affected product surface, operating system, Python and Node versions, commit or version, exact steps, expected result, actual result, and sanitized logs.

## Security and conduct

Do not request security help through a public issue. Follow [SECURITY.md](SECURITY.md). Community behavior is governed by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Response expectations

There is no guaranteed response time or service-level agreement. Clear reproductions and focused questions are easier for maintainers and contributors to answer.
